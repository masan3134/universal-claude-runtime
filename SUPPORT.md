# Support / Destek

## Get help / Yardım alın

For installation, provider profile, tmux, upgrade, or documentation questions:

- Email: info@gaiai.ai
- Website: https://gaiai.ai
- Public, non-sensitive bugs: GitHub Issues in this repository

Kurulum, provider profil, tmux, upgrade veya dokümantasyon soruları için info@gaiai.ai adresini veya repository issue'larını kullanın.

## Before contacting support / Destek öncesi

Read:

1. [Installation](docs/INSTALLATION.md)
2. [Troubleshooting](docs/TROUBLESHOOTING.md)
3. [Operations](docs/OPERATIONS.md)
4. [Security](SECURITY.md)

Include the exact command, redacted error, exit status, OS/architecture, Claude Code version, selected profile, tmux enabled/disabled state, and repository commit.

Tam komut, redact edilmiş hata, exit status, OS/architecture, Claude Code version, profil, tmux durumu ve repository commit'ini ekleyin.

## Never send / Asla göndermeyin

- secrets.env or environment dumps;
- API tokens or provider account credentials;
- SSH private keys, VPS passwords, or recovery codes;
- private source code or prompts unless an approved secure channel exists;
- unredacted logs containing user/customer data.

## Security issues / Güvenlik sorunları

Do not open a public issue. Follow [SECURITY.md](SECURITY.md) and email info@gaiai.ai.

Public issue açmayın. SECURITY.md sürecini izleyerek info@gaiai.ai adresine bildirin.

## Service level / Hizmet seviyesi

This open repository currently provides no guaranteed response time, uptime SLA, provider availability guarantee, or managed VPS support. Provider billing and account support remain with the provider.

Bu açık repository şu an garantili cevap süresi, uptime SLA, provider erişilebilirlik garantisi veya managed VPS desteği sunmaz. Provider faturalama ve hesap desteği provider'a aittir.
